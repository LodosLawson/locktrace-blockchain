🖥️ Run Your Own Node (Linux / macOS / Windows)

Join the decentralized network! Run an independent node on your local machine or VPS, sync the complete ledger, verify Proof-of-Work blocks locally, and announce your node in real-time.

Run in Terminal (Ubuntu / Debian / CentOS / Arch):
git clone https://github.com/LodosLawson/locktrace-blockchain.git
cd locktrace-blockchain
pip3 install -r requirements.txt
python3 node_runner.py --name "My-Linux-Node" --location "Istanbul, Turkey"
Run in Terminal (macOS with Python 3):
git clone https://github.com/LodosLawson/locktrace-blockchain.git
cd locktrace-blockchain
chmod +x scripts/run_node.sh
./scripts/run_node.sh
Run in Windows PowerShell:
git clone https://github.com/LodosLawson/locktrace-blockchain.git
cd locktrace-blockchain
.\scripts\run_node.ps1
