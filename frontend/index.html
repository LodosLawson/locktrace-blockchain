Geliştirici API & Merkeziyetsiz Düğüm / Web Sunucu Kurulumu

Kendi bilgisayarınızda veya sunucunuzda bağımsız P2P PoW + Doğrulayıcı düğüm ve SHA-256 imzalı yerel Web Cüzdanı çalıştırın. Her blok ödülünün %70'i PoW üreticisine, %30'u ise aktif ECDSA doğrulayıcı düğümlere dağıtılır.

1. Yerel (Local) veya Sunucu (Server) Olarak Frontend + Node Çalıştır
node_runner.py İndir download
A) Yerel Bilgisayarda Aç (Sadece Size Özel)
python node_runner.py --local --open SHA-256 + ECDSA bütünlüğünü doğrular ve cüzdanı http://127.0.0.1:5050 adresinde açar.
B) Genel Web & RPC Sunucusu Olarak Aç
python node_runner.py --server --port 5050 Ağdaki tüm cihazlara http://SUNUCU_IP:5050 üzerinden doğrulanmış Web Arayüzü ve P2P RPC sunar.
